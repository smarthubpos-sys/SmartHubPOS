SMART HUB POS - LOGIN FIX

1. Fungua folder ya project yako SmartHubPOS_Full.
2. Nakili src/components/ui/signin.tsx kutoka kwenye folder hii, uiweke kwenye project yako kwenye njia ileile, na ukubali Replace.
3. Hakikisha terminal ya `npx convex dev` inaendelea kufanya kazi.
4. Katika terminal nyingine, ndani ya project, endesha `npm run dev` kama app haijafunguka tayari.
5. Refresh browser na jaribu kuingia kwa username `admin` na nenosiri uliloweka wakati wa sign up.

Marekebisho: login sasa inatuma pia email ya ndani inayolingana na akaunti ya Convex Auth (`username@login.smarthub.invalid`). Hii haitumi email halisi.
