# Anza hapa - login ya kwanza

1. Endesha `ANZA_ADMIN.ps1` (PowerShell). Itakuuliza username ya Super Admin na kuiweka kama `SUPER_ADMIN_USERNAME` kwenye Convex.
2. Kwenye skrini ya login bonyeza "Usajili wa kwanza wa msimamizi", kisha fanya usajili kwa username hiyo na **password utakayochagua mwenyewe** (angalau herufi 10).
3. Hakuna password ya default. Usiandike password kwenye faili, chat au Git.

Ikiwa ulitumia toleo la zamani la mfumo huu lililokuwa na password ya mfano iliyochapishwa kwenye nyaraka, **badilisha password ya akaunti hiyo sasa**.
