# Marekebisho (SmartHubPOS)
- Bidhaa/group/unit: zinaonekana kwenye tawi zilipoandikishwa; zikiingizwa wakati "idara zote" imechaguliwa (bila branch) zinaonekana matawi yote. Hazitegemei tena access.ts mpya.
- Wateja: super admin anaona wote wa biashara; meneja wa tawi lake; mhudumu wake tu (+ wa zamani wasio na mmiliki).
- Printer: QZ Tray hupakiwa yenyewe, printer husomwa ukurasa ukifunguka, default huchaguliwa, na chapa hutumwa byte-exact.
- PIN: username hukumbukwa kwenye kifaa.
Hazijaendeshwa: build, codegen, test, lint.
